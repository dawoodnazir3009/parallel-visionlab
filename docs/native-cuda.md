# Native CUDA build and protocol

## Build

Run install-cuda.ps1, then build-cuda.ps1, or setup.ps1 -InstallNative. The local
installer uses the official CUDA 13.5 redistributable manifest and verifies each
component SHA-256. It installs compiler/runtime support under .tools/cuda without
changing the NVIDIA driver. Build tools/CMake/Ninja come from Visual Studio.

Verified development combination: nvcc 13.5.37, MSVC 19.51.36260 (Visual Studio
2026), Windows x64, RTX 4050 Laptop GPU. CMake compiles C++17/CUDA17 with static
CUDA and MSVC runtimes and architectures 75/86/89. The native executable passed
device and output tests; dumpbin reported KERNEL32.dll as its sole static import.
The installed NVIDIA driver is still required at execution time.

Default executable: native/cuda/build/Release/visionlab_cuda.exe. Portable builds
put it beside ParallelVisionLab.exe. Override with VISIONLAB_CUDA_PATH or Java
property visionlab.cuda.path. Availability means the executable exists; a missing
or incompatible device/driver produces an explicit operation error, never a
silent CPU fallback. Use --device on the native executable to check the GPU.

## Big-endian protocol version 1

All integers are unsigned 32-bit words; doubles are IEEE-754 64-bit, big-endian.

Request: magic 0x50564c31, width, height, operation, kernel size, size² double
coefficients, then width×height ARGB words. Operation 0=grayscale, 1=convolution,
2=Sobel. Non-convolution requests use a 1×1 identity coefficient. The native side
validates shape (at most 24 million pixels), odd kernel size 1-31, finite bounded
coefficients, exact payload consumption and operation IDs.

Response: magic 0x50564f31, width, height, kernel milliseconds, upload milliseconds,
download milliseconds, then width×height ARGB words. Java validates total length,
dimensions, magic and finite nonnegative timings. Each invocation uses a private
temporary directory; stdout/stderr go to a bounded diagnostic read from a file.
Timeout is 60 seconds by default. Cancellation kills the native process and
attempts temporary-file cleanup.

## Kernels

- Grayscale: one thread per pixel using the integer reference weights.
- Basic convolution: global-memory replicated-border sampling and ordered double
  accumulation. Sharpen/Gaussian use the coefficients generated by Java.
- Tiled convolution: 16×16 output block, cooperative halo loading to dynamic
  shared memory; all threads reach __syncthreads before out-of-range threads exit.
  Flattened tile indexing supports narrow/tall images without a small grid-y cap.
- Sobel: GPU grayscale followed by gradient/magnitude kernels on the same stream.

CUDA events bracket upload, kernel(s), and download separately. Process startup,
context creation, allocation, protocol and file overhead remain visible in Java's
bridge wall time. --fmad=false reduces cross-language accumulation differences.
GPU comparison permits RGB error ≤1 and requires exact alpha. The tiled variant
optimizes memory reuse; no universal speedup is assumed.
